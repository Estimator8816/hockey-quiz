# Как установить игру на iPhone

Ссылки-приглашения лежат в `docs/ссылки.md` (только на маке, в репозиторий не попадают).
Каждая ссылка многоразовая: новый телефон входит той же ссылкой.

Как это устроено: у иконки на iPhone своё хранилище, не как у Safari, и iPhone может не сохранить в иконке
код приглашения. Поэтому ссылку переносим через буфер: в Safari карточка «Установить на экран „Домой“» →
«Скопировать ссылку»; при первом запуске с иконки экран «Подключение» → «Вставить ссылку» (нужен интернет).
Дальше иконка открывается сразу: у сына игра, у родителя статистика (PIN только при первом входе).
Старую иконку — удалить и поставить заново.

## Телефон Данилы
1. Открыть ссылку «Данила» в **Safari** на его iPhone — откроется главный экран игры.
2. Внизу карточка «Установить на экран „Домой“» → «Скопировать ссылку».
3. «Поделиться» → «На экран „Домой“» → «Добавить».
4. Открыть иконку → «Вставить ссылку» → главный экран игры. Дальше — только с иконки.

Ссылку Данилы **не открывать на телефоне родителя**: этот телефон станет «телефоном сына».

## Телефоны папы и мамы
1. Открыть свою ссылку («Папа» или «Мама») в Safari, ввести PIN → «Родителям».
2. Вверху карточка «Установить на экран „Домой“» → «Скопировать ссылку».
3. «Поделиться» → «На экран „Домой“» → «Добавить».
4. Открыть иконку → «Вставить ссылку» → ввести PIN → статистика. Дальше иконка открывает её сразу.

## Проверка после установки
- На телефоне Данилы игра открывается главным экраном с кнопками (сама не начинается); пройти тренировку.
- Выключить интернет: матч играется. Включить: на телефоне папы матч появился.
- Закрыть игру смахиванием посреди матча и открыть снова: игра работает, незаконченный матч не засчитан.
- Заблокировать экран посреди матча меньше чем на 3 минуты: таймер стоит, гола нет.
